The agent runs git, gh and vercel against your own folders and sign-ins — something no web page is permitted to do, this one included. So the two commands below are copied, not run: you paste them into your own terminal, which is the only place they could work. Two minutes, once.
1 Node.js
node -v
Skip this if node -v already prints a version. Otherwise the command above installs it, or download it from nodejs.org. It is what provides npx in step 2.
2 Start ship-it
npx github:aleco-art/ship-it
Why npx.cmd and not npx: PowerShell resolves the bare name to npx.ps1, which Windows refuses to load under its default Restricted execution policy — you get UnauthorizedAccess on a perfectly good install. The .cmd shim is exempt and works in both PowerShell and cmd, so nothing about your security settings has to change.

What the agent does

Eight phases. The four in amber are gates: if one fails the run stops and tells you why, instead of leaving you half-shipped.

01 · gate
Preflight
Tools, both sign-ins, repo state. Stops before touching anything.
02
Recon
Framework, package manager, scripts, existing docs.
03 · gate
Secret scan
Fixes .gitignore, refuses to commit a live credential.
04 · gate
Local build
Runs your real production build before anything remote exists.
05
Env vars
Finds every variable your code reads, writes .env.example, pushes them to Vercel.
06
Docs
README from verified facts only — every command in it was actually run.
07
GitHub + Vercel
Creates or reuses the repo, connects git, deploys to production.
08 · gate
Verify
Fetches the live URL and confirms a push auto-deploys.

Why that order. It is sorted by what a mistake costs to find.

Failure found…Costs
in reconseconds
in the local production build~1 minute
in the Vercel builda push, 2–5 min, a log dig
after the production deploya broken public URL
after a secret is pushedrotating every key

So: secrets before git, build before deploy, docs before the first commit — and never create anything remote to find out whether the local state was valid. Half-shipped reported as success is worse than a clean stop.

Honest limits

  • It saves the most time once per project. After the first ship, git push already deploys. This automates the setup you do once and never remember.
  • Vercel-shaped projects only. Static, Next.js, Vite, Astro, SvelteKit, Nuxt, Remix. A long-running server, websocket or background worker does not run on serverless functions — the agent stops and says so rather than shipping something broken.
  • Read the README it writes. Built from verified facts, still worth your eyes.
  • A run costs tokens on your Claude account.
  • Private by default. Public repos happen only when you pick public.
