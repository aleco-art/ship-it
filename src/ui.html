What the agent does

Eight phases. The four marked in amber are gates: if one fails the run stops and tells you why, instead of leaving you half-shipped.

01 · gate
Preflight
Tools, both sign-ins, repo state. Stops before touching anything.
02
Recon
Framework, package manager, scripts, existing docs.
03 · gate
Secret scan
Fixes .gitignore and refuses to commit a live credential.
04 · gate
Local build
Runs your real production build before anything remote exists.
05
Env vars
Finds every variable your code reads and writes .env.example.
06
Docs
README from verified facts only — every command was actually run.
07
GitHub + Vercel
Creates or reuses the repo, pushes env vars, connects git, deploys.
08 · gate
Verify
Fetches the live URL and confirms a push auto-deploys.

Why this order. It is sorted by what a mistake costs to find. A broken build costs a minute locally and five on Vercel. A leaked key costs rotating every credential. So: secrets before git, build before deploy, docs before the first commit — and never create anything remote to find out whether the local state was valid.
