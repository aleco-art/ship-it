ship-it

Paste a folder you run on localhost.
Get a documented GitHub repo and a live Vercel URL.

An agent that does the whole first deploy: secret scan, production build, environment variables, README, repo, deploy, and a check that the live page actually loads. It runs on your machine and uses the sign-ins you already have.

npx github:aleco-art/ship-it

Opens a local control panel at 127.0.0.1. MIT licensed.

Why that order

The phases are sorted by what a mistake costs to find. Everything cheap to check happens before anything expensive to undo.

Failure found…Costs
in reconseconds
in the local production build~1 minute
in the Vercel builda push, 2–5 min, a log dig
after the production deploya broken public URL
after a secret is pushedrotating every key

So: secrets before git, build before deploy, docs before the first commit — and never create anything remote to find out whether the local state was valid. A gate that fails stops the run and tells you why. Half-shipped reported as success is worse than a clean stop.

What you need

Git

Almost certainly already installed.

GitHub CLI

gh auth login — the official OAuth flow.

Vercel CLI

vercel login — same idea.

Claude Code

The agent itself. Signs in on first run.

The panel detects what is missing and gives each one an Install or Connect button that opens a terminal and runs the command for you. You finish the sign-in there, in the official CLI. No token, password or one-time code ever passes through this app — it only watches for the session to appear.

Honest limits

  • It saves the most time once per project. After the first ship, git push already deploys. This automates the setup you only do once — which is exactly the part nobody remembers how to do.
  • Vercel-shaped projects only. Static sites, Next.js, Vite, Astro, SvelteKit, Nuxt, Remix. A long-running server, a websocket, or a background worker does not run on serverless functions — the agent stops and says so rather than shipping something broken.
  • Read the README it writes. It is built from facts the agent verified, not invented, and every command in it was actually executed. It is still worth thirty seconds of your eyes.
  • It costs tokens. A run is a real Claude Code session on your account.
  • Private by default. Public repos happen only when you pick public.
